# Transport tracker guide

Approved narrated tracker tutorial, 1080 × 1920, H.264/AAC, 4:17. Source: Bravo-K9-Tracker-Guide-With-Voice.mp4.

The build reassembles these parts and checks the full SHA-256 before copying the video into public assets. The poster, WebVTT captions and chapter transcript are versioned alongside the player. Media loads only after a visitor chooses Play or a chapter. No Runway content was used.
